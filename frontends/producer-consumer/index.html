How It Works

The producer-consumer problem is a classic synchronization scenario where:

  • Producer creates items and places them in a shared buffer
  • Consumer takes items from the buffer and processes them
  • The buffer has fixed capacity (5 slots)

The Petri net enforces synchronization using buffer_space tokens as a capacity counter:

  • Producer needs a buffer_space token to start producing (blocks when buffer full)
  • Consumer needs a buffer token to start consuming (blocks when buffer empty)
  • When consumer finishes, a buffer_space token is returned

This elegant pattern uses complementary places (buffer + buffer_space = constant) to model bounded capacity without guards or inhibitor arcs.
