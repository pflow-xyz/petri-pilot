How It Works

This models a bang-bang thermostat controller using a Petri net with ODE dynamics:

  • heat transition: fires when heater_on has a token, increases temperature (rate-based)
  • cool transition: fires continuously, decreases temperature proportional to current value
  • turn_on / turn_off: toggle heater state based on temperature vs target

The ODE solver simulates continuous dynamics. The heater toggles create a feedback loop: temperature oscillates around the setpoint because the heater overshoots slightly before turning off, then undershoots before turning back on.

This is a classic control systems pattern. Real thermostats add hysteresis (deadband) to prevent rapid cycling.
